# IoT Gateway Placement Simulator — Complete Project

A software-only IoT/WSN simulation comparing random and K-Means gateway placement, gateway-count selection, single-gateway-failure resilience, and direct versus multi-hop routing. It includes Python experiments, CSV outputs, six figures, and a browser-based interactive dashboard.

> **Scientific honesty:** this is a mathematical simulation, not a physical IoT deployment. Results are generated by the included code and assumptions. They must not be described as hardware measurements. For publication-quality claims, repeat the experiments over multiple deployment/traffic seeds and report means and uncertainty intervals.

## Contents

- `gateway_placement.py` — placement, expected energy, lifetime, plots 1–3, `results.csv`.
- `gateway_extended.py` — elbow/silhouette/cost analysis, fault tolerance, multi-hop lifetime, plots 4–6, `extended_results.csv`.
- `gateway_sim.html` — interactive dashboard; runs locally in a modern browser, no server/API/key required.
- `requirements.txt` — Python dependencies.
- `validate_project.py` — syntax, runtime, CSV and image-output checks; reruns both experiments.
- `results.csv`, `extended_results.csv` — generated numerical outputs from the latest run.
- `1_placement_comparison.png` … `6_multihop_lifetime.png` — generated charts.
- `MODEL_AND_METHODOLOGY.md` — model equations, definitions, assumptions, and limitations.

## Requirements

- Python 3.10 or newer recommended.
- Internet is required only to install Python packages for the first time.
- Browser: current Chrome, Edge, Firefox, or Safari for the HTML dashboard.

## Installation (Windows)

1. Extract the ZIP to a normal folder, for example `C:\IoT_Gateway_Project`.
2. Open that folder in File Explorer.
3. Click the address bar, type `cmd`, and press Enter.
4. Run:

   ```bat
   py -m venv .venv
   .venv\Scripts\activate
   python -m pip install --upgrade pip
   pip install -r requirements.txt
   ```

5. Run the experiments:

   ```bat
   python gateway_placement.py
   python gateway_extended.py
   ```

6. Open `gateway_sim.html` by double-clicking it. The dashboard does not need Python or an internet connection.

## Installation (Linux/macOS)

```bash
python3 -m venv .venv
source .venv/bin/activate
python -m pip install --upgrade pip
pip install -r requirements.txt
python gateway_placement.py
python gateway_extended.py
```

## One-command validation

After installing requirements, run:

```bash
python validate_project.py
```

It compiles both Python files, runs both simulations, and checks that the expected CSV and PNG files exist and are readable. It can take a minute or two depending on the computer. A successful run ends with `VALIDATION PASSED`.

## Dashboard controls

- Adjust node count and gateway count.
- Run/step K-Means, re-roll random gateway positions, or redeploy sensor nodes.
- Select direct or multi-hop routing and toggle backup/failover.
- Start/pause battery simulation, reset batteries, and fail the busiest gateway.
- Calculate the lowest modeled total cost across candidate gateway counts.

The dashboard uses a heuristic browser implementation of K-Means and a simplified routing model; its stochastic values need not exactly equal Python outputs. It is intended for interactive exploration, not as a substitute for the reproducible Python experiments.

## How to cite/use results in a report

State the node count, area, packet size, radio model, initial battery, transmission probability, communication ranges, seed, and whether an energy figure is expected load or all-nodes-transmit full load. The base experiment's `expected_energy_per_round_J` includes the configured transmission probability; `full_load_energy_per_round_J` is the reference case where every node transmits in every round. Do not compare these two columns as if they represented the same traffic load.

## Troubleshooting

- `No module named numpy/matplotlib/sklearn`: activate `.venv` and run `pip install -r requirements.txt`.
- `py` not recognized on Windows: install Python from python.org and enable **Add Python to PATH**, then use `python` instead of `py`.
- Graphs/CSVs not updating: run commands from the extracted project directory; output files are written to the current working directory.
- Browser dashboard looks blank: use a current browser and ensure JavaScript is enabled.
